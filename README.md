# Конспекты Honer AI

Красиво оформленные конспекты: рамки, блоки, таблицы, лента времени, картинки и интерактивный тест с автопроверкой.

## Файлы

| Файл | Тема |
|:---|:---|
| `istoriya-ot-rusi-do-ordy.html` | История России: от Древней Руси до ордынского ига (IX–XV вв.) |
| `trehfazny-tok.html` | Трёхфазный ток: звезда и треугольник |

## Как посмотреть

1. Открой файл в репозитории и нажми **Download raw file** — файл скачается.
2. Открой скачанный файл в браузере: увидишь оформленную страницу.
3. Хочешь PDF — на странице «Печать» → «Сохранить как PDF».
4. Тест внизу страницы работает прямо в браузере и считает баллы.
