## Как открыть красивую версию

1. Открыть файл в репозитории (нажать на его название).
2. Справа сверху — кнопка со стрелкой **«Download raw file»** (скачать).
3. Открыть скачанный файл двойным нажатием — он откроется в браузере уже с рамками, цветными блоками и тестом.

Либо включить GitHub Pages в настройках репозитория и читать по обычной ссылке.

## Как устроено

- Спокойная палитра: синие блоки — главное, красный — ловушки, зелёный — итоги.
- В конце интерактивный тест: считает баллы сам и подсвечивает верные ответы.
- Печать: Ctrl+P → «Сохранить в PDF» — получается готовый файл-шпаргалка.
