# Конспекты Honer AI

Оформленные конспекты: рамка-лист, спокойные блоки, таблицы, шпаргалка и интерактивный тест с автопроверкой. Без картинок — страницы открываются быстро и работают без VPN.

## Файлы

| Файл | Тема |
|:---|:---|
| `index.html` | оглавление со ссылками на все конспекты |
| `elektrichestvo.html` | Электричество: ток, напряжение, сопротивление, закон Ома, мощность, соединения, безопасность |
| `matrizy-obratnaya.html` | Матрицы: обратная матрица 3-го порядка (метод присоединённой) и решение уравнения AX = B |
| `teplovoe-rele.html` | Тепловое реле: назначение, устройство, уставка, классы 10/20/30, ловушки, тест |
| `teplovoe-rele-urok.html` | Тепловое реле: конспект занятия по аудиозаписи — устройство по пунктам, режимы возврата, колесико уставки, пример с двигателем, тест |

Открыть страницу → «Печать» → «Сохранить как PDF». Рамки и блоки сохраняются.

## Заметки

- Репозиторий публичный, страницы доступны по ссылке.
- Тест внизу страницы работает прямо в браузере и считает баллы.
- Оглавление `index.html` содержит только те файлы, которые реально лежат в репозитории: удалённые темы в него не попадают.
- `matrizy-obratnaya.html` — решение задания 4 (пункты 2 и 3) и задания 5: полный ход с определителями, алгебраическими дополнениями, транспонированием и проверкой; пункт 1 оставлен в блоке «Для сверки».
- `teplovoe-rele-urok.html` — конспект по записи занятия (28:35). Расшифровка была автоматической, поэтому формулировки приведены в читаемый вид, а не дословно. Вопрос преподавателя «что находится между нагревателем и биметаллической пластиной» в записи остался без ответа — отмечен в файле как открытый.
