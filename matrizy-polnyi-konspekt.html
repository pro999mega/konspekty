📐 Матрицы: что это, виды, действия со строками

Часть 1 · обозначения, размер, особые виды, элементарные преобразования

Что учить в первую очередь

  1. Размер. m строк × n столбцов — от него зависит, что вообще можно делать.
  2. Два действия над строками: менять местами и прибавлять строку с множителем. На определитель влияет ещё умножение строки на число.
  3. Ступентатый вид — то, к чему приводят любую матрицу для ранга и решения систем.

Определение и обозначение

Матрица — прямоугольная таблица чисел. Числа внутри называются элементами, у каждого два индекса: aij — i-я строка, j-й столбец.

a₁₁a₁₂a₁₃ a₂₁a₂₂a₂₃

Размер записывают так: 2×3 — 2 строки и 3 столбца. Матрицу размера m×n коротко пишут A = (aij), где i = 1…m, j = 1…n.

Равенство и матрица как преобразование

Две матрицы равны, только если одинаковый размер и все элементы совпадают. Из этого решают уравнения: A = B ⟹ a11 = b11, a12 = b12 и так далее.

Квадратная матрица задаёт линейное преобразование: точку (x; y) она переводит в (a·x + b·y; c·x + d·y). Строки матрицы показывают, куда переходят единичные векторы.

A·(x; y)ᵀ,  где A = [ a b ; c d ]
x′ = a·x + b·y
y′ = c·x + d·y

Пример: уравнение с элементами

Дано: [ x+1 2 ; 3 y−1 ] = [ 4 2 ; z 5 ].

x + 1 = 4  →  x = 3
2 = 2        ✓
3 = z    →  z = 3
y − 1 = 5  →  y = 6

Транспонирование Aᵀ

Строки становятся столбцами, размер m×n превращается в n×m.

123 456
14 25 36

Свойства: (Aᵀ)ᵀ = A; (A + B)ᵀ = Aᵀ + Bᵀ; (A·B)ᵀ = Bᵀ·Aᵀ — порядок меняется.

Элементарные преобразования строк

  1. Перестановка двух строк: определитель меняет знак.
  2. Умножение строки на k ≠ 0: определитель умножается на k.
  3. Прибавление к строке другой строки, умноженной на k: определитель не меняется.

Если этими действиями одна матрица получена из другой, они эквивалентны: у них одинаковый ранг, а значит и одинаковые решения системы.

Ступенчатый вид: полный проход

Приводим 3×3 к ступенчатому виду сверху вниз:

[ 1  2  1 | 4 ]
[ 2  5  3 | 9 ]
[ 3  7  4 |13 ]

R2 − 2R1:  [ 1  2  1 | 4 ]
           [ 0  1  1 | 1 ]
           [ 3  7  4 |13 ]

R3 − 3R1:  [ 1  2  1 | 4 ]
           [ 0  1  1 | 1 ]
           [ 0  1  1 | 1 ]

R3 − R2:   [ 1  2  1 | 4 ]
           [ 0  1  1 | 1 ]
           [ 0  0  0 | 0 ]

Число ненулевых строк — это ранг. Здесь ранг = 2, значит одна переменная свободная: решений бесконечно много.

🪤 Ловушки

  1. Путать строки и столбцы: a23 — это 2-я строка, 3-й столбец, а не наоборот.
  2. Считать, что 2×2 и 2×2 равны всегда — нужно совпадение всех элементов.
  3. Забывать, что размер меняется при транспонировании.
  4. Переставлять столбцы в системе так же спокойно, как строки: столбцы соответствуют переменным, порядок меняется вместе с ними.

✖️ Операции над матрицами

Часть 2 · сложение, умножение на число, умножение матриц, свойства

Что учить в первую очередь

  1. Сложение — только одинакового размера, поэлементно.
  2. Умножение A·B — строка на столбец; требуется, чтобы столбцов A было столько же, сколько строк B.
  3. A·B ≠ B·A — это главная ловушка всей темы.

Сложение и вычитание

Складывают поэлементно и только одинаковые по размеру матрицы.

[ 1  2  3 ]   [ 4  5  6 ]   [ 5  7  9 ]
[ 7  8  9 ] + [ 1  1  1 ] = [ 8  9 10 ]

Свойства: A + B = B + A; (A + B) + C = A + (B + C); A + O = A.

Умножение на число

Каждый элемент умножается на это число.

3 · [ 1  2 ]   [ 3  6 ]
      [ 0 −1 ] = [ 0 −3 ]

Свойства: (αβ)A = α(βA); α(A + B) = αA + αB; (α + β)A = αA + βA.

Умножение матриц: правило

A размера m×n, B размера n×k. Результат — m×k. Элемент cij = сумма произведений i-й строки A на j-й столбец B.

cij = ai1b1j + ai2b2j + … + ainbnj

Мнемоника: по горизонтали умножаем, по вертикали складываем. Размеры «соседние» n должны совпасть: (m×n)·(n×k) = m×k.

Пример 1: 2×2 на 2×2

A = [ 2 1 ; 3 4 ], B = [ 1 0 ; 2 5 ].

c11 = 2·1 + 1·2 = 4        c12 = 2·0 + 1·5 = 5
c21 = 3·1 + 4·2 = 11       c22 = 3·0 + 4·5 = 20

A·B = [ 4   5 ]
      [ 11 20 ]

Пример 2: 2×3 на 3×2

A = [ 1 2 1 ; 0 1 3 ], B = [ 1 2 ; 0 1 ; 2 1 ].

c11 = 1·1 + 2·0 + 1·2 = 3      c12 = 1·2 + 2·1 + 1·1 = 5
c21 = 0·1 + 1·0 + 3·2 = 6      c22 = 0·2 + 1·1 + 3·1 = 4

A·B = [ 3 5 ]
      [ 6 4 ]

B·A = [ 1 2 ]   [ 1 2 1 ]   [ 1  4  7 ]
      [ 0 1 ] · [ 0 1 3 ] = [ 0  1  3 ]
      [ 2 1 ]               [ 2  5  5 ]

Здесь A·B — 2×2, а B·A — 3×3. Результаты не только разные, у них разный размер: коммутативности нет.

Пример 3: сколько разными способами складывать

C = [1 2 3] · (2; 1; 4) = 1·2 + 2·1 + 3·4 = 2 + 2 + 12 = 16

Вектор-строка на вектор-столбец даёт число — это скалярное произведение.

Свойства умножения

Работает всегда

  • A(BC) = (AB)C — ассоциативность
  • A(B + C) = AB + AC
  • A·E = E·A = A
  • A·O = O

Не работает

  • AB ≠ BA
  • из AB = O не следует A = O или B = O
  • нельзя сокращать: AB = AC ещё не значит B = C

Возведение в степень

Только для квадратных: Aⁿ = A·A·…·A (n раз). A⁰ = E.

A = [ 1 1 ; 0 1 ]

A² = [ 1 1 ; 0 1 ]·[ 1 1 ; 0 1 ] = [ 1 2 ; 0 1 ]
A³ = A²·A = [ 1 3 ; 0 1 ]
Aⁿ = [ 1 n ; 0 1 ]

След матрицы

Сумма диагональных элементов: tr A = a₁₁ + a₂₂ + … Для [2 1; 3 4] след = 2 + 4 = 6. Полезно: tr(AB) = tr(BA).

🪤 Ловушки

  1. Проверять размеры до умножения: если столбцы A ≠ строки B, произведение не существует.
  2. Умножать «в лоб» поэлементно: [1 2; 3 4]·[5 6; 7 8] ≠ [5 12; 21 32].
  3. Писать AB = BA, не проверив — это ошибка почти всегда.
  4. В степени перемножать элементы вместо матриц, хотя для «некоторых» матриц A² выглядит просто.

Шпаргалка

αA — каждый элемент на α
A·B: (m×n)·(n×k) = m×k, c_ij = строка i · столбец j
AB ≠ BA;  A·E = A;  (AB)ᵀ = BᵀAᵀ
Aⁿ только для квадратной, A⁰ = E
tr A — сумма диагонали

Чек-лист самопроверки

  • Сразу считаю размер результата
  • Умножаю 2×3 на 3×2 без ошибок
  • Помню, что AB ≠ BA
  • Знаю роль единичной матрицы
  • Считаю степень и след
Пример с необратимостьюA = [1 0; 0 0], B = [0 0; 3 5]. AB = [0 0; 0 0], хотя ни A, ни B не нулевые. Правило «произведение равно нулю, значит один множитель ноль» для матриц не работает.

🔍 Определитель и ранг

Часть 3 · 2×2, 3×3, свойства, миноры и алгебраические дополнения, ранг

Что учить в первую очередь

  1. 2×2: ad − bc — считается в голове.
  2. 3×3: правило треугольника или разложение по строке.
  3. Смысл: det = 0 — матрица вырождена, обратной нет, система либо несовместна, либо имеет бесконечно много решений.

det 2×2

A = [ a b ; c d ]
det A = |A| = a·d − b·c

Пример: [ 3 4 ; 2 5 ]  →  3·5 − 4·2 = 15 − 8 = 7

det 3×3: правило треугольника

A = [ a b c ; d e f ; g h i ]

det = aei + bfg + cdh − ceg − bdi − afh
      (три «плюсовых» диагонали минус три «минусовых»)

det 3×3: разложение по строке

Разложение по первой строке — самый надёжный способ и то, что нужно для алгебраических дополнений:

det A = a·M₁₁ − b·M₁₂ + c·M₁₃

где M₁ⱼ — минор: определитель матрицы без строки 1 и столбца j. Знаки идут по шаблону + − +.

+−+ −+− +−+

Знак элемента — это (−1)i+j. Минор со знаком называется алгебраическим дополнением: Aij = (−1)i+j·Mij.

Пример: один определитель тремя способами

A = [ 2 1 1 ; 1 2 1 ; 1 1 2 ].

Способ 1 — треугольники

плюсы: 2·2·2 + 1·1·1 + 1·1·1 = 8 + 1 + 1 = 10
минусы: 1·2·1 + 1·1·2 + 2·1·1 = 2 + 2 + 2 = 6
det A = 10 − 6 = 4

Способ 2 — разложение по первой строке

det A = 2·(2·2 − 1·1) − 1·(1·2 − 1·1) + 1·(1·1 − 2·1)
      = 2·3 − 1·1 + 1·(−1)
      = 6 − 1 − 1 = 4

Способ 3 — приведение к треугольному виду

[ 2 1 1 ; 1 2 1 ; 1 1 2 ]
R2 − ½R1, R3 − ½R1:  [ 2  1   1  ]
                     [ 0  1,5 0,5]
                     [ 0  0,5 1,5]
R3 − (1/3)R2:        [ 2  1   1  ]
                     [ 0  1,5 0,5]
                     [ 0   0  4/3]
det = 2 · 1,5 · 4/3 = 3 · 4/3 = 4

Все три способа дают 4 — так и проверяют себя на контрольной.

Пример: матрица с разложением по третьему столбцу

B = [ 1 0 2 ; 0 3 0 ; −1 0 4 ]. Удобно разложить по второму столбцу — там два нуля.

det B = +3 · (1·4 − 2·(−1)) = 3 · (4 + 2) = 18

Ранг матрицы

Ранг — наибольший порядок ненулевого минора, то есть число независимых строк (или столбцов).

  • Приводят матрицу к ступенчатому виду — ранг = число ненулевых строк.
  • Или ищут миноры возрастающего порядка: 2×2, потом 3×3 и так далее.
D = [ 1  2  3 ]
    [ 2  4  6 ]
    [ 1  1  1 ]

R2 − 2R1 → [ 0 0 0 ];  R3 − R1 → [ 0 −1 −2 ]
Ступенчатый вид: две ненулевые строки → ранг = 2
(строка 2 была копией строки 1 в 2 раза, поэтому «пропала»)

Связь с определителем: у квадратной матрицы порядка n ранг равен n тогда и только тогда, когда det ≠ 0. Если det = 0 — ранг меньше n, матрица вырождена.

Система уравнений и det

Квадратная система A·x = b
det A ≠ 0 → единственное решение (x = A⁻¹b)
det A = 0 → либо нет решений, либо бесконечно много

Правило Крамера:
x_i = det A_i / det A, где A_i — A с заменой i-го столбца на b

Пример: 2x + y = 5, x + y = 3
det A = 2·1 − 1·1 = 1
det A₁ = |5 1; 3 1| = 5 − 3 = 2 → x = 2
det A₂ = |2 5; 1 3| = 6 − 5 = 1 → y = 1

🪤 Ловушки

  1. Забыть знак дополнения: у (1;2), (2;1), (2;3), (3;2) минус.
  2. Разложить по строке, в которой больше нулей — но сбиться в знаках. Считай шаблон явно.
  3. Считать det только по диагонали: для 3×3 это ошибка.
  4. Путать det(kA) = kⁿdet A с умножением одной строки.
  5. Говорить «решения нет», когда det = 0: вариантов два — нет решений или бесконечно много.

  1. Условие: обратная есть только у квадратной с det ≠ 0.
  2. Формула: A⁻¹ = (1/det A) · Aᵀ, где Aᵀ — транспонированная матрица дополнений.
  3. Проверка: A⁻¹·A = E — одно умножение, которое ловит все арифметические ошибки.

Определение

A⁻¹ — такая матрица, что A·A⁻¹ = A⁻¹·A = E. Существует только если матрица квадратная и det A ≠ 0.

Свойства: (A⁻¹)⁻¹ = A; (AB)⁻¹ = B⁻¹A⁻¹; (Aᵀ)⁻¹ = (A⁻¹)ᵀ; det(A⁻¹) = 1/det A.

Метод присоединённой матрицы: 4 шага

det → дополнения → транспонировать → разделить на det
  1. Посчитать det A. Ноль — обратной нет, дальше решать нечего.
  2. Для каждого элемента посчитать алгебраическое дополнение Aij = (−1)i+j·Mij.
  3. Поставить их в матрицу по своим местам и транспонировать — получится присоединённая A*.
  4. Разделить все элементы на det A.

Пример 1: матрица 2×2

A = [ 2 1 ; 1 1 ].

Шаг 1: det A = 2·1 − 1·1 = 1

Шаг 2: A₁₁ = +1        A₁₂ = −1
       A₂₁ = −1        A₂₂ = +2

Шаг 3: Aᵀ = [ 1 −1 ; −1 2 ]

Шаг 4: делим на 1, значит A⁻¹ = [ 1 −1 ; −1 2 ]

Проверка:

(1;1): 2·1 + 1·(−1) = 1      (1;2): 2·(−1) + 1·2 = 0
(2;1): 1·1 + 1·(−1) = 0      (2;2): 1·(−1) + 1·2 = 1
Получили E ✓

Пример 2: стандартная матрица 3×3

B = [ 2 1 1 ; 1 2 1 ; 1 1 2 ].

Шаг 1: det B = 4  (считали в части про определитель)

Шаг 2 — дополнения (матрица симметричная, поэтому дополнения повторяются по диагонали):

B₁₁ = +3    B₁₂ = −1    B₁₃ = −1
B₂₁ = −1    B₂₂ = +3    B₂₃ = −1
B₃₁ = −1    B₃₂ = −1    B₃₃ = +3

Шаг 3 — транспонирование ничего не меняет (матрица симметричная). Шаг 4 — делим на 4:

3/4−1/4−1/4 −1/43/4−1/4 −1/4−1/43/4 
Проверка (1;1): 2·3/4 + 1·(−1/4) + 1·(−1/4) = 6/4 − 1/4 − 1/4 = 1  ✓
Проверка (1;2): 2·(−1/4) + 1·3/4 + 1·(−1/4) = −2/4 + 3/4 − 1/4 = 0  ✓

Пример 3: матрица, где транспонирование реально меняет вид

C = [ 1 0 2 ; 0 3 0 ; −1 0 4 ].

Шаг 1: det C = 18 ≠ 0 → обратная есть

Шаг 2 — дополнения из таблицы выше:

Матрица дополнений

1203 060 −603

После транспонирования

120−6 060 303

Шаг 4 — делим на 18:

2/30−1/3 01/30 1/601/6 
Проверка (1;1): (2/3)·1 + 0·0 + (−1/3)·(−1) = 2/3 + 1/3 = 1  ✓
Проверка (1;3): (2/3)·2 + 0·0 + (−1/3)·4 = 4/3 − 4/3 = 0      ✓

Решение уравнения A·X = B

Умножаем обе части слева на A⁻¹: A⁻¹·A·X = A⁻¹·B, то есть X = A⁻¹·B. Порядок обязателен — справа A⁻¹·A уже не получится.

Дано: A = [ 2 1 ; 1 1 ], B = (5; 3).

det A = 1, A⁻¹ = [ 1 −1 ; −1 2 ]

x₁ = 1·5 + (−1)·3 = 2
x₂ = (−1)·5 + 2·3 = 1

Ответ: x₁ = 2, x₂ = 1
Проверка: 2·2 + 1·1 = 5 ✓ ;  1·2 + 1·1 = 3 ✓

Если уравнение записано как X·A = B, то умножают справа: X = B·A⁻¹.

Проверка методом Гаусса

Альтернатива присоединённой: приписать к A единичную матрицу и приводить к виду (E | A⁻¹).

[ A | E ] → преобразования строк → [ E | A⁻¹ ]

[ 2 1 | 1 0 ]  R1−R2  [ 1 0 | 1 −1 ]
[ 1 1 | 0 1 ]  ────→  [ 1 1 | 0  1 ]
                      R2−R1  [ 1 0 | 1 −1 ]
                      ────→  [ 0 1 | −1 2 ]

Правая часть совпала с присоединённым методом: A⁻¹ = [ 1 −1 ; −1 2 ].

🪤 Ловушки

  1. Забыли транспонировать. Матрица дополнений — ещё не присоединённая.
  2. Делят только диагональ вместо всех элементов.
  3. При det = 0 пишут «0» вместо «обратной не существует».
  4. В A·X = B умножают справа: X = B·A⁻¹ — ошибка.
  5. Не делают проверку A⁻¹·A = E.
  6. Меняют знак не у всех дополнений с нужным индексом.

Шпаргалка

A⁻¹ = (1/det A) · Aᵀ  (Aᵀ — транспонированная матрица дополнений)
A_ij = (−1)^(i+j) · M_ij
det A = 0 → A⁻¹ не существует
(AB)⁻¹ = B⁻¹A⁻¹ ;  (Aᵀ)⁻¹ = (A⁻¹)ᵀ
A·X = B → X = A⁻¹B   (умножаем слева!)
X·A = B → X = B·A⁻¹  (умножаем справа)
Проверка: A⁻¹·A = E
Гаусс: [A | E] → [E | A⁻¹]

Чек-лист самопроверки

  • Считаю det 3×3 разложением по строке
  • Ставлю верные знаки дополнений
  • Транспонирую матрицу дополнений
  • Делю на det все элементы
  • Делаю проверку A⁻¹·A = E
  • В A·X = B умножаю слева
Быстрый способ для 2×2[a b; c d]⁻¹ = 1/(ad − bc) · [d −b; −c a]. Меняем местами диагональ, у побочных элементов меняем знак, делим на определитель.
