Матрицы: от определения до метода Крамера

Всё по порядку, с формулами и проверенными примерами · 6 разделов

1. Определение и виды

Главное
Матрица — прямоугольная таблица чисел из m строк и n столбцов. Размер пишут всегда так: m × n (сначала строки, потом столбцы).

Матрица размера m × n:

A =
a11a12…a21a22…⋮⋮amn
 = (aij),  i= 1..m,  j= 1..n

Индексы — это адрес элемента: aij = строка i, столбец j. Первый индекс всегда строка.

Виды матриц

ВидПризнак
Квадратнаяm = n, порядок n
Нулеваявсе элементы = 0
Единичная Eпо диагонали 1, остальное 0
Диагональнаяненулевые только на главной диагонали
Треугольнаянули выше или ниже диагонали
Симметричнаяaij = aji, то есть Aᵀ = A
Ступенчатаякаждая строка начинается правее предыдущей
Вектородна строка (1×n) или один столбец (m×1)
Пример: что за матрица
200020002
→ квадратная 3×3, диагональная, симметричная. Главная диагональ: 2, 2, 2.

2. Операции

Сложение и умножение на число

Только для одинаковых размеров, поэлементно: cij = aij + bij, cij = λ·aij.

Умножение матриц

Правило
A·B возможно ⇔ число столбцов A равно числу строк B. Тогда cij = Σ ais·bsj — берём i-ю строку первой и j-й столбец второй. Размер результата: (m×k)·(k×n) = m×n.
Пример умножения
A = 1230−12 (2×3), B = 1021−13 (3×2) → результат 2×2.
c11 = 1·1 + 2·2 + 3·(−1) = 1 + 4 − 3 = 2
c12 = 1·0 + 2·1 + 3·3 = 0 + 2 + 9 = 11
c21 = 0·1 + (−1)·2 + 2·(−1) = 0 − 2 − 2 = −4
c22 = 0·0 + (−1)·1 + 2·3 = 0 − 1 + 6 = 5
AB = 211−45

Порядок важен: в общем случае AB ≠ BA, а иногда BA вообще не существует (размеры не сходятся).

Транспонирование

Строки становятся столбцами: (Aᵀ)ij = aji.

Пример
A = 1230−12 (2×3) → Aᵀ = 102−132 (3×2)

Свойства: (Aᵀ)ᵀ = A; (A + B)ᵀ = Aᵀ + Bᵀ; (AB)ᵀ = Bᵀ·Aᵀ (порядок меняется!).

3. Определитель

Определитель det A = |A| = Δ — это число, которое сопоставляют квадратной матрице. У прямоугольной определителя нет.

|A| = a11a12a21a22 = a11a22 − a12a21

3-й порядок: правило Саррюса

Δ = a11a22a33 + a12a23a31 + a13a21a32
   − a13a22a31 − a11a23a32 − a12a21a33

Минор и алгебраическое дополнение

Минор Mij — определитель, оставшийся после вычёркивания i-й строки и j-го столбца.
Алгебраическое дополнение Aij = (−1)i+j·Mij.

Универсальный способ — разложение
Δ = сумма по любой строке (или столбцу): Δ = Σ aij·Aij. Выбирай строку с нулями — работать меньше.
Пример: один и тот же det двумя способами
A = 123014560

Саррюс. Плюсы: 1·1·0 = 0; 2·4·5 = 40; 3·0·6 = 0 → 40.
Минусы: 3·1·5 = 15; 2·0·0 = 0; 1·4·6 = 24 → 39.
Δ = 40 − 39 = 1.

Разложение по 1-й строке.
1·(1·0 − 4·6) = −24
−2·(0·0 − 4·5) = −2·(−20) = 40
+3·(0·6 − 1·5) = 3·(−5) = −15
Δ = −24 + 40 − 15 = 1. Совпало.

Свойства

  1. det E = 1, det нулевой = 0.
  2. det Aᵀ = det A.
  3. Перестановка двух строк меняет знак.
  4. Строка умножилась на k → весь det умножился на k. Для матрицы n×n: det(kA) = kn·det A.
  5. Две одинаковые (или пропорциональные) строки → det = 0.
  6. Прибавили к строке другую строку с коэффициентом → det не изменился.
  7. det(AB) = det A · det B.
  8. det треугольной = произведение диагонали.

4. Обратная матрица и ранг

Обратная матрица

A−1 — такая, что A·A−1 = A−1·A = E.

Условие существования
Обратная есть только если det A ≠ 0 (матрица невырожденная).
A−1 = 1det A · A11A21…A12A22………Ann   — дополнения стоят транспонированными
Пример: вся обратная матрица
A = 123014560, det A = 1 (см. раздел 3).

Дополнения:

A11 = +(1·0 − 4·6) = −24   A12 = −(0·0 − 4·5) = 20   A13 = +(0·6 − 1·5) = −5
A21 = −(2·0 − 3·6) = 18   A22 = +(1·0 − 3·5) = −15   A23 = −(1·6 − 2·5) = 4
A31 = +(2·4 − 3·1) = 5   A32 = −(1·4 − 3·0) = −4   A33 = +(1·1 − 2·0) = 1

Транспонируем и делим на 1:

A−1 = −2418520−15−4−541

Проверка 1-й строки A·A−1: 1·(−24) + 2·20 + 3·(−5) = −24 + 40 − 15 = 1; 1·18 + 2·(−15) + 3·4 = 18 − 30 + 12 = 0; 1·5 + 2·(−4) + 3·1 = 5 − 8 + 3 = 0. Первая строка результата — (1, 0, 0). Остальные дают (0, 1, 0) и (0, 0, 1), то есть E.

Второй способ — Гаусс–Жордан

Приписываем справа единичную: (A | E). Приводим левую часть к E — справа получается A−1.

Мини-пример
A = 2153, det = 2·3 − 1·5 = 1, значит A−1 = 3−1−52.
Проверка: 2·3 + 1·(−5) = 1; 2·(−1) + 1·2 = 0; 5·3 + 3·(−5) = 0; 5·(−1) + 3·2 = 1 ✓

Ранг

Ранг — наибольший порядок ненулевого минора. Он же — число ненулевых строк в ступенчатом виде.

Пример
123246111
II − 2·I = (0, 0, 0); III − I = (0, −1, −2).
Минор из I и III строк: 1·1 − 2·1 = −1 ≠ 0 → ранг ≥ 2. Третьей независимой строки нет: rang = 2.

Элементарные преобразования строк (перестановка, умножение на λ ≠ 0, прибавление другой строки) ранг не меняют. rang A ≤ min(m, n).

5. Системы линейных уравнений

A·x = b,  Am×n,  x — столбец неизвестных,  b — столбец свободных членов
Кронекер–Капелли
Система совместна ⇔ rang A = rang (A | b).
Если общий ранг r = n → решение единственное. Если r < n → решений бесконечно много, свободных переменных n − r.
Пример несовместной системы
x + y = 2; 2x + 2y = 5.
(A|b) = [[1, 1 | 2], [2, 2 | 5]]; II − 2·I = (0, 0 | 1).
rang A = 1, rang (A|b) = 2 → система несовместна.

Как выбрать метод

1
Уравнений столько же, сколько неизвестных?
↓ да
2
det A ≠ 0?
↓ да
3
Крамер или матричный метод (x = A−1b)
↓ нет / размеры не совпадают
4
Метод Гаусса + Кронекер–Капелли

Метод Крамера

Только для квадратной системы при Δ ≠ 0:

xi = ΔiΔ,   Δi — det A, в котором i-й столбец заменён столбцом b
Сквозной пример: три метода — один ответ

x₁ + x₂ + x₃ = 6
2x₁ − x₂ + x₃ = 3
x₁ + 2x₂ − x₃ = 2

A = 1112−1112−1, b = 632

Определитель:
1·((−1)(−1) − 1·2) = −1
−1·(2·(−1) − 1·1) = −(−3) = 3
+1·(2·2 − (−1)·1) = 5
Δ = −1 + 3 + 5 = 7

Крамер:
Δ₁ = 6·1 − 1·(−5) + 1·8 = −6 + 5 + 8 = 7 → x₁ = 7/7 = 1
Δ₂ = 1·(−5) − 6·(−3) + 1·1 = −5 + 18 + 1 = 14 → x₂ = 14/7 = 2
Δ₃ = 1·(−8) − 1·1 + 6·5 = −8 − 1 + 30 = 21 → x₃ = 21/7 = 3

Гаусс:
(A|b) → R₂ − 2R₁ = (0, −3, −1 | −9), R₃ − R₁ = (0, 1, −2 | −4).
Меняем R₂ и R₃ местами, затем R₃ + 3R₂ = (0, 0, −7 | −21).
Обратный ход: x₃ = 3; x₂ = −4 + 2·3 = 2; x₁ = 6 − 2 − 3 = 1.

Ответ: x = (1; 2; 3). Проверка: 1 + 2 + 3 = 6 ✓; 2 − 2 + 3 = 3 ✓; 1 + 4 − 3 = 2 ✓

Матричный метод

x = A−1·b при det A ≠ 0.

Для той же системы
A−1 = 17 −1323−215−1−3
x = 1/7·(−6 + 9 + 4; 18 − 6 + 2; 30 − 3 − 6) = 1/7·(7; 14; 21) = (1; 2; 3) ✓

Метод Гаусса

1
Прямой ход — расширенная матрица (A|b) приводится к ступенчатому виду
2
Обратный ход — неизвестные находятся снизу вверх подстановкой

Универсален: любые m и n, det может быть любым. Появилась строка (0 … 0 | c ≠ 0) → система несовместна.

Ловушки — здесь теряют баллы
1. Забыли транспонировать матрицу алгебраических дополнений в A−1.
2. Переставили местами A·B — результат другой.
3. Применили Крамер, не проверив Δ ≠ 0.
4. В Δi заменили не тот столбец: заменяется именно i-й, остальные остаются.
5. Считают det(kA) как k·det A, а надо kn·det A.
6. Путают ранг с размером матрицы: rang ≤ min(m, n).
Вся тема за 10 секунд
Матрица — таблица чисел. det — число, которое проверяет: сжимает ли матрица пространство в ноль. det ≠ 0 → есть A−1 и единственное решение. Крамер — для маленьких квадратных систем, Гаусс — для всего остального, Кронекер–Капелли — чтобы узнать, есть ли решение вообще.

6. Самопроверка

Формула перемножения и условие умножения cij = Σs ais·bsj; нужно число столбцов A = число строк B.
det для матрицы 2×2: [[3, 7], [1, 4]] 3·4 − 7·1 = 12 − 7 = 5.
Когда система точно несовместна? Когда rang A ≠ rang (A|b) — появляется строка (0 … 0 | c ≠ 0).
Как выбрать строку для разложения? Любую, но выгоднее ту, где больше нулей — меньше миноров считать.

Мини-тест

1. Что нужно проверить перед умножением A·B?
A. det A ≠ 0 · B. A и B квадратные · C. Столбцы A = строки B
ОтветC.
2. Чему равен det матрицы [[2, 5], [1, 3]]?
A. 1 · B. 11 · C. −1
Ответ2·3 − 5·1 = 1 → A.
3. det A = 0. Что из этого верно?
A. Есть обратная матрица · B. Обратной нет, Крамер неприменим · C. rang A = 0
ОтветB (rang при этом может быть любым меньше n).
4. В формуле обратной матрицы матрица алгебраических дополнений…
A. Остаётся как есть · B. Транспонируется · C. Умножается на det A
ОтветB, и потом делится на det A.
5. n = 4, rang A = rang (A|b) = 2. Сколько решений?
A. Одно · B. Ни одного · C. Бесконечно много
ОтветC; свободных переменных 4 − 2 = 2.
