Обратная матрица 3-го порядка и матричное уравнение

Решено по образцу из тетради: det → алгебраические дополнения → транспонирование → деление на det → проверка

Что здесь решено

  1. Задание 4, п.2 — обратная для B (3×3), det B = 4.
  2. Задание 4, п.3 — обратная для C (3×3), det C = 18.
  3. Задание 5 — решение уравнения A·X = B, то есть X = A−1·B.

Пункт 1 (матрица A, det = 1) в тетради уже решён верно — внизу блок «Для сверки».

Метод присоединённой матрицы за 4 шага

1. det A → 2. дополнения → 3. транспонировать → 4. разделить на det

1Считаем определитель. Если он равен нулю — обратной матрицы не существует, дальше идти некуда.

2Для каждого элемента вычёркиваем его строку и столбец, берём определитель 2-го порядка и ставим знак: плюс, если сумма номеров строки и столбца чётная, минус, если нечётная.

3Матрицу из дополнений обязательно транспонируем — иначе получится не тот результат.

4Делим транспонированную матрицу на определитель: A−1 = (1 / det A) · AT, где AT — транспонированная таблица дополнений.

Задание 5 — матричное уравнение A·X = B

Дано:

21 11
5 3

Идея: умножаем обе части слева на A−1 и получаем X = A−1·B. Порядок важен: именно A−1 слева, потому что A−1·A = E.

Шаг 1. Определитель:

det A = 2·1 − 1·1 = 2 − 1 = 1   (≠ 0, обратная есть)

Шаг 2. Дополнения и транспонирование:

A11 = +1      A12 = −1
A21 = −1      A22 = +2

AT = [ 1  −1 ;  −1  2 ]

Шаг 3. Обратная матрица (делим на det = 1, поэтому она совпадает с AT):

1−1 −12

Шаг 4. Умножаем на B:

x1 = 1·5 + (−1)·3 = 5 − 3 = 2
x2 = (−1)·5 + 2·3  = −5 + 6 = 1
2 1

Ответ: x1 = 2, x2 = 1.

Проверка подстановкой в A·X = B:

2·2 + 1·1 = 5   ✓
1·2 + 1·1 = 3   ✓

🪤 Где обычно теряют баллы

  1. Знак дополнения. Он равен (−1)i+j: у элементов (1;2), (2;1), (2;3), (3;2) знак минус, у (1;1), (1;3), (3;1), (3;3) и середины (2;2) — плюс.
  2. Забыли транспонировать. Матрица дополнений — это ещё не присоединённая. В C это видно сразу: без транспонирования элемент (3;1) остался бы −6 вместо 3.
  3. Делить надо все элементы, а не только диагональ.
  4. det = 0 — писать «обратной не существует», а не «ноль».
  5. В уравнении A·X = B умножают слева: X = A−1·B. Запись B·A−1 — ошибка.
  6. Не забывай финальную проверку A−1·A = E: одно умножение, а спасает от всех арифметических промахов.

Шпаргалка

A−1 = (1 / det A) · AT
AT — транспонированная матрица алгебраических дополнений

Aij = (−1)i+j · Mij
Mij — минор: вычеркнуть строку i и столбец j
