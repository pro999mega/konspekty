Метод присоединённой матрицы за 4 шага

1. det A → 2. дополнения A(ij) → 3. транспонировать → 4. разделить на det

1Считаем определитель. Если он равен нулю — обратной матрицы не существует, дальше идти некуда.

2Для каждого элемента вычёркиваем его строку и столбец, берём определитель 2-го порядка и ставим знак: плюс, если сумма номеров строки и столбца чётная, минус, если нечётная (шахматка).

3Матрицу из дополнений обязательно транспонируем — иначе получится не тот результат.

4Делим транспонированную матрицу на определитель: A⁻¹ = (1/det A) · Aᵀ.

Задание 5 — матричное уравнение A·X = B

Дано:

21 11
5 3

Идея: умножаем обе части слева на A⁻¹, получаем X = A⁻¹·B. Порядок важен: именно A⁻¹ слева, потому что A⁻¹·A = E.

Шаг 1. Определитель:

det A = 2·1 − 1·1 = 2 − 1 = 1   (≠ 0, обратная есть)

Шаг 2. Дополнения и транспонирование:

A₁₁ = +1      A₁₂ = −1
A₂₁ = −1      A₂₂ = +2

Aᵀ = [ 1  −1 ;  −1  2 ]

Шаг 3. Обратная матрица (делим на det = 1, поэтому она совпадает с Aᵀ):

1−1 −12

Шаг 4. Умножаем на B:

x₁ = 1·5 + (−1)·3 = 5 − 3 = 2
x₂ = (−1)·5 + 2·3  = −5 + 6 = 1
2 1

Ответ: x₁ = 2, x₂ = 1.

Проверка подстановкой в A·X = B:

2·2 + 1·1 = 5   ✓
1·2 + 1·1 = 3   ✓

🪤 Где обычно теряют баллы

  1. Знак дополнения. Берётся (−1)^(i+j): у элементов (1;2), (2;1), (2;3), (3;2) знак минус, у (1;1), (1;3), (3;1), (3;3) — плюс, середина (2;2) — плюс.
  2. Забыли транспонировать. Матрица дополнений — это ещё не присоединённая. В C это видно сразу: без транспонирования элемент (3;1) остался бы −6 вместо 3.
  3. Делить надо все элементы, а не только диагональ.
  4. det = 0 → обратной нет, писать «не существует», а не «0».
  5. В уравнении A·X = B умножают слева: X = A⁻¹B. Запись B·A⁻¹ — ошибка.
  6. Не забывай финальную проверку: A⁻¹·A = E — это одно умножение, а спасает от всех арифметических промахов.

Шпаргалка

A⁻¹ = (1/det A) · Aᵀ,  где Aᵀ — транспонированная матрица алгебраических дополнений

A(i;j) = (−1)^(i+j) · M(i;j)     M — минор: вычеркнуть строку i и столбец j
